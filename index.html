2. 你的照片与音乐：只在本机

  • 照片：本应用通过 Android 系统相册接口（MediaStore） 读取你选择的图片，用于在屏幕上显示。图片始终留在你的设备上， 不会被复制到别处、不会被上传、不会用于训练任何模型。
  • 音乐：内置曲目随安装包分发（CC0 / 公共领域，见应用内「音乐与版权」页）。 你自己导入的音乐只是设备上的文件路径引用，文件本身不会被上传。
  • 设置：转场选择、播放时长、亮度调度等应用设置保存在应用私有目录， 卸载即删除。配置文件导出功能由你本人主动触发并选择保存位置， 文件只落在你指定的地方。

3. 唯一的对外网络请求：天气（可选）

天气浮层默认关闭。只有当你主动打开天气浮层并填写城市后， 本应用才会向 Open-Meteo 发起请求：

发送内容用途
你填写的城市名（如"杭州"，纯文本）解析成经纬度
解析出的经纬度（保留 4 位小数，约 11 米精度）查询当前气温与天气

本应用不申请定位权限（ACCESS_FINE_LOCATION / ACCESS_COARSE_LOCATION 均未在清单中声明）。天气用的坐标来自 城市名解析，不是你设备的真实位置 —— 所以它既不知道你在哪，也无法定位到你。 Open-Meteo 是开源气象服务，其隐私做法见其官网。本应用不向它发送任何 设备标识、用户标识或你的照片。

关于「网络共享」（SMB / WebDAV，专业版功能）的额外说明：连接你自己家里的 NAS 时， 地址、账号与密码都只保存在这台设备上（密码经系统密钥库加密，且不随配置文件导出）； 服务器地址与凭据不会发往任何第三方，本应用也不收集它们。 家庭 NAS 的 WebDAV 通常只提供明文 http，因此本应用允许与你自己手输的局域网地址 之间使用明文连接 —— 它不会把任何内容发往互联网。若你的 NAS 使用 https 而证书是自签的， 本应用会放行该证书（家用设备几乎都是自签）——这意味着这条链路上无法防中间人攻击。 如果你在意这一点，请只在可信的家庭局域网内使用该功能，或改用 SMB （本应用对 SMB 同样只做局域网直连）。

本应用不申请：定位、相机、麦克风、通讯录、日历、电话、短信。 需要"屏幕保护程序"能力时用的是系统已有的 DreamService 机制，不额外申请权限。

6. 数据删除

由于本应用不收集、不存储任何服务器端数据，没有"你的数据"需要删除。

  • 应用内数据（设置、收藏标记、隐藏标记、撤销记录、专业版权益缓存）全部在设备私有目录， 卸载应用即全部删除。
  • 如需只清除设置而不卸载：Android 系统设置 → 应用 → 本应用 → 存储 → 清除数据。

This is not "not wired up yet" — it is part of the product's positioning. The App is a one-time purchase; revenue comes from that purchase, so we have no need to monetise data. Not collecting data is a feature, not a cost — and it is our core difference from free photo-frame apps.

2. Your photos and music stay on your device

  • Photos: the App reads the images you select through Android's system gallery API (MediaStore) in order to show them on screen. Your images never leave your device — they are not copied elsewhere, not uploaded, and not used to train any model.
  • Music: built-in tracks ship inside the install package (CC0 / public domain — see the in-app "Music & Licences" page). Music you import yourself is only a reference to a file path on your device; the file itself is never uploaded.
  • Settings: transitions, slide duration, brightness schedule and similar settings are stored in the App's private directory and are removed when you uninstall. The config-file export is triggered by you, and the file is written only where you choose.

3. The only outbound request: optional weather

The weather overlay is off by default. Only after you enable it and type a city does the App contact Open-Meteo:

What is sentPurpose
The city name you typed (plain text, e.g. "Hangzhou")Resolve to coordinates
Resolved coordinates (4 decimal places, approx. 11 m precision)Fetch current temperature / conditions

The App requests no location permission (ACCESS_FINE_LOCATION / ACCESS_COARSE_LOCATION are not declared in the manifest). The coordinates used for weather come from geocoding a city name, not from your device's real position — so the App cannot know where you are. Open-Meteo is an open-source weather service; see its website for its privacy practices. The App sends it no device identifier, user identifier, or photos.

About network shares (SMB / WebDAV, a Pro feature): when connecting to your own NAS, the address, username and password are stored only on this device (the password is encrypted with the system keystore and is not included in config exports). Server addresses and credentials are never sent to any third party and are not collected by us. Home-NAS WebDAV typically offers plain HTTP only, so the App permits a plaintext connection to a LAN address you typed yourself; it never sends anything to the internet. If your NAS uses HTTPS with a self-signed certificate, the App accepts that certificate (home devices almost always are self-signed) — which means man-in-the-middle protection is not possible on that link. If that matters to you, use this feature only on a trusted home LAN, or use SMB (which the App also connects to over the LAN only).

The App does not request: location, camera, microphone, contacts, calendar, phone, or SMS. Its screensaver capability uses the system's existing DreamService mechanism and requests no additional permissions.

5. Children

The App is not directed at children and collects no one's personal information (see §1), so no special handling of children's data applies. Parents can let children use it to display photos — it uploads nothing.

6. Data deletion

Because the App collects and stores no server-side data, there is no "your data" to delete.

  • In-app data (settings, favourite markers, hidden markers, undo history, Pro entitlement cache) lives in the device private directory and is fully removed on uninstall.
  • To clear settings without uninstalling: Android Settings → Apps → this App → Storage → Clear data.

7. Changes to this policy

If a future version adds any collection behaviour (for example cloud albums, which would necessarily involve transferring photos), this policy will be updated before the change takes effect and highlighted in-app.

The App's existing commitments do not change: core features (on-device gallery, folder picker, full shuffle coverage, hide a photo, real screensaver, resident playback, 20 built-in music tracks) are free forever, with no watermark, no time limit, and no ads.
