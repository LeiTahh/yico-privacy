## What this app does

Yico Photo Slide Frame turns your device into a photo frame. It does **not**
collect your photos, does **not** upload them, has **no account system**,
**no ads**, and **no third-party analytics SDK**.

The only outbound network request is an optional weather overlay, which sends
a city name only (no device identifier, no location permission).
